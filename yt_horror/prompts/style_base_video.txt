# It differs from the image base on purpose. A video model is asked for a moving
# shot, so it must not be told the scene is a "still" - that word invites a frozen
# frame. The camera terms that work on a still ("handheld micro drift", "push in")
# are the same vocabulary a video model uses for actual motion, so they are kept.
