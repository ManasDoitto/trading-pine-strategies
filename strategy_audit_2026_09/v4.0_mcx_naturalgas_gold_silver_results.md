# Crude v4.0's logic on other MCX commodities: Natural Gas, Gold, Silver (14 Sep 2026)

## Why this test, and why not "tune crude to PF>1.5"

The user asked for crude PF above 1.5, and separately asked to test the same strategy on Natural Gas, Gold
and Silver (MCX). The first half of that request repeats a request already answered two days ago: a proper
train/holdout validation found no crude strategy in this repo clears even PF 1.3 without overfitting the same
fixed 29.7-month history (see `protected-crude-script.md` memory, "Train/holdout validation" entry). Chasing
1.5 on the same data would mean re-running that overfitting risk with an even higher, less realistic bar --
declined for the same reason as before, not because 1.5 is an arbitrary number.

**The second half is a fair, different question**: does v4.0's exact SHA-flip/EMA9-22/swing-stop/RR3 logic
generalize to other MCX commodities? That's testing an already-proven strategy against new instruments, not
re-tuning it against the same data -- no overfitting risk. Tested here.

## Method

Same multi-asset audit copy used for the original XAUUSD/BTCUSD sweep (`A93_v4.0_mcx_multiasset.pine.txt`),
logic byte-identical to the protected script. Session filter ON (crude's own default "0915-2330"), since these
are MCX commodities trading similar hours to crude -- unlike the 24/7 gold/crypto case, no session patch was
needed. Same tiled non-overlapping-window method, 0.02%/side commission, no added slippage, 5m, full available
history on each symbol (`MCX:NATURALGAS1!`, `MCX:GOLD1!`, `MCX:SILVER1!`).

## Reading

**None of the three clears 1.5. None even clearly beats crude's own 1.09.** This is the same pattern seen
everywhere else this strategy has been tested this project (BankNifty v0.4's 1.33 remains the only strategy
in this repo above 1.15 with real statistical weight):

- **Natural Gas is a net loser** (PF 0.95, -78.5 pts) -- close to breakeven but still negative across 11
  windows. The SHA-flip signal doesn't translate to gas's price action.
- **Gold and Silver are both modest winners**, PF 1.06-1.07, in the same range as crude itself -- not an
  improvement, a lateral move. Both show the same pattern already flagged for crude in the 2-year analysis:
  concentrated gains in specific windows (Gold: +24,172 in one window alone, ~1.8x the entire 32-month net;
  Silver: +34,548 and +35,024 in the two most recent windows, together larger than the full-period net) rather
  than steady edge across the whole period. That's the same "most of the edge is one or two volatile windows,
  not a durable signal" issue already documented for crude -- worth the same skepticism here.
- **Silver's drawdown is large in absolute terms** (45,815 pts in one window) because its point value is high
  and the underlying is volatile -- sized at 1 lot this would be a serious equity swing, same caveat as
  BTCUSD's large point-value drawdowns in the earlier gold/crypto sweep.

## Bottom line

**This strategy family's edge tops out around PF 1.05-1.14 across every instrument tested so far** (crude,
gold MCX, silver MCX, and marginally XAUUSD) **except BankNifty v0.4, which is a structurally different
strategy** (EMA pullback + 15m ADX gate, not SHA-flip). Testing v4.0's logic on three more commodities
reinforces, rather than breaks, the pattern already established: nothing in this repo's tested strategy space
reaches PF 1.5 without overfitting a fixed dataset. If PF 1.5+ is the real target, it likely requires either a
genuinely new entry idea (not a variant of SHA-flip or EMA-pullback) or accepting a much smaller, thinner
sample (the way SMC v1.1's 1.40 PF on crude came with only 86 trades).
