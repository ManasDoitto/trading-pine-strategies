# Crude v2.0-E: hard SL cap, win/loss cooldown, scale-out (13 Sep 2026)

Script: `v2.0-E crudeoil strategy 5min (hard SL cap + win-loss cooldown + scale-out trail).pine.txt`.
It is v2.0 with three optional changes; every other rule is untouched.

## How it was tested

- MCX:CRUDEOIL1! 5m, the same 11 non-overlapping windows as the full audit (Mar 2024 to Sep 2026, 29.7 months).
- 0.02% commission per side, no slippage. Results are points per lot.
- The test copy trades 2 lots so that the 50% scale-out can split. Each trade is scored as one result: both halves are summed and then divided by the lots traded.
- **Check:** with every change switched off, the file reproduces v2.0 exactly: 246 trades and +108 on the live window, and the identical row on window 7.
- The v2.0 baseline below is the audited v2.0 run. For window 7 it uses the all-off run on the same dates, because the audited run started 2 days later.

## Reading

- **Hard SL cap:** the average loss falls as intended, from −28.9 to −25.6, and trades fall only 4%. But the cap removes the wide-stop trades, and those were v2.0's biggest winners in the volatile 2026 windows (+2,688 → +413, +1,387 → −77). In the quiet windows it blocks nothing. It helps in three older losing windows, but not enough. **Net: 3,407 points worse.**
- **Win/loss cooldown:** close to neutral, 401 points worse, with one more positive window. v2.0 already waits 3 bars after any exit, so there are few pile-on re-entries left to remove.
- **Scale-out:** the win rate rises from 38% to 45% and max drawdown falls by 411, but the average win drops from 51.7 to 37.7. It cuts short the big trend trades that v2.0 earns its money from. **Net: 772 points worse.** It needs at least 2 lots, because 1 lot cannot be split.
- **Combined:** the downsides stack. All three together is the worst setting.

**Verdict:** keep v2.0 unchanged. The only change worth considering is scale-out alone, and only if a smoother equity curve matters more than total points.
